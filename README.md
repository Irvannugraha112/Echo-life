# EchoLife

**Personal Continuity Operating System**

EchoLife menyimpan, memahami, dan meneruskan lapisan digital kehidupan seseorang — kebiasaan, keputusan, refleksi, dan shared echo dengan orang terdekat.

- Agent-first (Vision Keeper hanya review brief mingguan)
- Retensi tinggi lewat nilai kontinuitas + network effect personal
- Passive income: subscription + family plan
- Privacy by design

## North Star Metric
Weekly Active Continuity Moments

## Struktur (rencana)
- `apps/web` — Next.js frontend
- `apps/api` — FastAPI backend
- `agents/` — Multi-agent system (33 agents)
- `docs/` — Product Bible & architecture

## Stack
| Layer | Choice |
|-------|--------|
| Frontend | Next.js + TypeScript + Tailwind |
| Backend | FastAPI |
| Database | PostgreSQL + pgvector |
| Payments | Stripe |
| Deploy | Vercel |
